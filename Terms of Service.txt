## Description of Service

The Bot provides the following features:

- Tracks when users join and leave Discord voice and stage channels.
- Records session data including join time, leave time, channel, and duration.
- Stores attendance records in Firebase Firestore.
- Provides Discord slash commands for administrators to view and manage attendance.
- Provides a health API endpoint for uptime monitoring.
- Intentionally **does not** record voice channel switches as attendance.
